# 🌱 EcoCompare

> Compare products based on environmental impact and make smarter, greener choices.

EcoCompare is a web-based sustainable product comparison tool designed to help users evaluate products through environmental and sustainability-focused metrics and make more informed purchasing decisions.

## 🚀 Live Demo

**Live Website:** https://eco-compare-cpef.vercel.app/

## ✨ Features

- 🌱 Compare sustainable products side-by-side
- 📊 Green Score for evaluating environmental performance
- ♻️ Environmental impact and sustainability metrics
- 🔍 Product search and category filtering
- ⚖️ Multi-product comparison
- 🧮 Sustainability calculator
- 📚 Sustainability education and learning section
- 📈 Dashboard and comparison history
- 💾 Persistent session data using local storage
- 📱 Responsive design for desktop, tablet and mobile
- ⚡ Fast and modern Vite-powered interface
- 🛡️ User-friendly loading, empty and error states

## 🛠️ Tech Stack

- **Frontend:** React
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **State Management:** React Context
- **Data Persistence:** Browser Local Storage
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## 🎯 Purpose

EcoCompare aims to make sustainability easier to understand by bringing environmental information into a simple product-comparison experience.

Instead of looking at products only through price or conventional specifications, users can explore sustainability-related factors and make greener choices.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/hxrshit25/EcoCompare.git
cd EcoCompare
```

### 2. Install dependencies

```bash
npm install --legacy-peer-deps
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
